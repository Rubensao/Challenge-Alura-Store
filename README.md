# Análisis de Datos: Alura Store

Este proyecto forma parte del desafío del curso **Python para Data Science** de Alura Latam. El objetivo fue realizar un análisis de ventas de las cuatro tiendas de Alura Store, con el fin de ayudar al Sr. Juan a tomar una decisión estratégica sobre cuál tienda vender.

## Objetivo

Evaluar el desempeño de las tiendas considerando:

- Facturación total
- Categorías más populares
- Calificación promedio de clientes
- Productos más y menos vendidos
- Costo promedio de envío

---

## Estructura del Proyecto

- `AluraStoreLatam.ipynb`: notebook principal con el análisis completo
- `base-de-datos-challenge1-latam/`: archivos CSV con datos de las tiendas

---

## Resultados Principales

- **Tienda con menor facturación:** Tienda 4
- **Mejor categoría en ventas:** Electrónicos
- **Tienda con mejores calificaciones:** Tienda 3
- **Producto más vendido:** TV LED UHD 4K
- **Tienda con menor costo de envío:** Tienda 4

---

## Recomendación Final

> Se recomienda vender **Tienda 4**, ya que muestra el menor desempeño global, permitiendo liberar recursos para invertir en una tienda más rentable.
